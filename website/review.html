Map administrator actions

Before staging an update, select reports to preview them together or delete them. Deletion does not change the baseline map.

  1. Load the new upstream map. Reports already present upstream are resolved automatically.
  2. Select the remaining reports you want to keep in addition to the upstream map.
  3. Preview the reviewed result and adjust the selection if necessary.
  4. Apply the reviewed update. Unselected reports are discarded.

Enter the map administrator API key to enable administrative actions.

Loading and previewing do not modify the baseline. Changes are committed only when the reviewed update is applied.
