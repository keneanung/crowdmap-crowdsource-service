Stage and apply an upstream map update

  1. Load the new upstream map. Exact matches are resolved; unchanged reports are carried forward; conflicts can be kept or dropped.
  2. Inspect incoming upstream against the reviewed result above.
  3. Apply the staged decision. The server rechecks the current baseline first.

Loading upstream does not modify the local map. Resolved reports are removed only when this final step succeeds.
