Reconcile a published map update

  1. Review reports and mark changes you know were incorporated upstream. Exact matches are removed automatically.
  2. Publish the corresponding upstream map and version files.
  3. Apply the update below. The server rechecks the baseline version before replacing files.

The server compares the old and new baseline at each reported target. It automatically removes reports satisfied by upstream and flags targets that upstream changed differently.
